## 💡 포트폴리오 원칙

### 성공 기준

- 포트폴리오는 "얼마나 많은가" 보다 "얼마나 잘 설명하고 증명하는가"
- 6개 프로젝트의 완성도 > 10개 프로젝트의 미완성
- 각 프로젝트는 "무엇을 증명하는가"가 한 문장으로 설명돼야 함
- 새 프로젝트를 추가하기 전, 기존 핵심 프로젝트 보강이 우선
- 자동화 도구는 "작지만 선명한 문제 해결"이면 충분히 가치가 있음

### 추가할 때 체크리스트

- [ ] README 첫 문단에 한 줄 정의 있는가
- [ ] 저장소를 열자마자 문제와 해결책이 보이는가
- [ ] 스크린샷/다이어그램/예시 응답 중 최소 하나가 있는가
- [ ] 현재 상태와 다음 단계가 명확한가
- [ ] 포트폴리오 페이지와 GitHub pin에서 일관된 톤인가
